# AWS SageMaker LLM Deployment & NLP Question Answering System

## Project Overview

This project demonstrates the deployment of state-of-the-art Natural Language Processing (NLP) and Large Language Models (LLMs) using Amazon SageMaker and Hugging Face.

The project includes two major implementations:

1. **Falcon-40B Large Language Model Deployment**
   - Deployment of the Falcon-40B-Instruct model using AWS SageMaker.
   - Real-time inference using Hugging Face inference containers.
   - Scalable cloud-based LLM hosting.

2. **NLP Question Answering System**
   - Deployment of DistilBERT-based Question Answering model.
   - Context-aware question answering using transformer architecture.
   - Real-time inference endpoint deployment on AWS.

This project showcases practical experience with cloud AI deployment, transformer models, NLP inference, and AWS infrastructure.
